Occurrence admission/repeat-after-completion, rejected dispatch, independent feed progress beyond 100 blocked rows, stale EOL ownership, Copilot cursor rollback, and demo seed transaction/overlap tests are in `SchedulerOverlapPostgresIntegrationTest`. Remaining maintenance overlap and full shutdown qualification are estimated at 1–2 engineering days, not a release commitment.

EOL/EPSS callbacks admit the latest due instant within 61 seconds; a later callback logs a missed admission rather than inventing a catch-up run. Copilot polls the same bounded UTC window. Daily feed keys use the UTC date. Persisted accepted work survives restart; these changes do not promise catch-up for every unadmitted EOL/Copilot occurrence during downtime. NVD continuity remains independently tracked under P16. Occurrence history uses existing sync-run retention; the Copilot cursor is progress data, removed with the tenant registry row.

Asset lifecycle, finding workflow/incident sync, suppression rules, projection repair, exposure freshness and the remaining QUALIFY rows stay open.
